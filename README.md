# autoscroll-bd.koplugin
Auto Scroll BD — gesture-controlled automatic scrolling plugin for KOReader
Auto Scroll BD

Automatic scrolling plugin for KOReader

Auto Scroll BD adds smooth, hands-free automatic scrolling to KOReader. It is designed especially for reading long-form content where you want the page to move continuously without repeatedly touching the screen.

Created by: Argho Rahamatullah

---

✨ Features

- 📖 Automatic continuous scrolling
- ▶️ Start and stop scrolling
- ⚡ Adjustable scrolling speed
- ➕ Increase scrolling speed
- ➖ Decrease scrolling speed
- 💾 Remembers your preferred scrolling speed
- 👆 Supports KOReader gestures
- 🖥️ Designed for smooth scrolling in Fast screen refresh mode
- 📱 Works with touch-enabled KOReader devices

---

📚 How It Works

Auto Scroll BD continuously moves the book/document upward at the selected speed.

Once Auto Scroll is started, the plugin periodically scrolls the current page. You can keep reading without manually swiping or turning the page.

The scrolling speed can be adjusted while reading.

Start / Stop

Use the Auto Scroll BD menu to start or stop automatic scrolling.

When scrolling is active, the page continuously moves upward.

To stop scrolling, use the Start / Stop action again.

---

⚙️ Recommended KOReader Setup

For the smoothest scrolling experience, two settings are particularly important.

1. Enable Continuous Mode

The document should be configured for continuous scrolling/page mode.

Auto Scroll BD is designed to move continuously through the document rather than treating each page as an isolated screen.

Recommended setup

Open the KOReader menu and enable the appropriate continuous page / continuous scrolling mode for your document.

If continuous mode is not enabled, the scrolling behavior may not feel seamless when reaching the end of a page.

---

2. Use Fast Screen Refresh Mode

For smooth automatic scrolling, use:

Screen Refresh → Fast

E-ink displays normally refresh relatively slowly. Using Fast refresh mode allows Auto Scroll BD to update the screen more frequently, producing a much smoother scrolling experience.

Recommended combination

«Continuous page mode + Fast refresh mode»

This is the recommended configuration for Auto Scroll BD.

⚠️ Battery consideration

Fast refresh mode may consume more battery than slower refresh modes.

If battery life is more important than smoothness, you can switch back to your preferred refresh mode.

👆 Gesture Setup

Auto Scroll BD can be controlled using KOReader's gesture system.

You can assign KOReader gestures to the Auto Scroll BD actions.

For example, you can configure:

Gesture| Action
Two-finger tap| Start / Stop
Swipe up| Increase speed
Swipe down| Decrease speed

The exact gestures are completely customizable in KOReader.

---

How to Assign a Gesture

1. Open a book in KOReader.

2. Open the KOReader menu.

3. Go to:
   
   Settings → Gesture Manager
   
   or the equivalent gesture configuration section on your KOReader version.

4. Select the gesture you want to configure.

5. Choose the Auto Scroll BD action.

You should see actions such as:

Auto Scroll BD: Start / Stop

Starts or stops automatic scrolling.

Auto Scroll BD: Speed +

Increases the scrolling speed.

Auto Scroll BD: Speed -

Decreases the scrolling speed.

Assign whichever gestures are comfortable for you.

---

🚀 Example Gesture Configuration

A convenient setup could be:

Two-finger tap

→ Auto Scroll BD: Start / Stop

Two-finger swipe up

→ Auto Scroll BD: Speed +

Two-finger swipe down

→ Auto Scroll BD: Speed -

This allows you to control automatic scrolling without opening the plugin menu.

---

💾 Speed Memory

Auto Scroll BD remembers your selected scrolling speed.

For example:

1. Start Auto Scroll BD.
2. Increase the speed until you find a comfortable reading speed.
3. Stop reading.
4. Open another book later.

Your preferred speed is retained, so you don't have to configure it again every time.

🔧 Installation

Copy the plugin folder:

autoscroll-bd.koplugin

into your KOReader plugins directory:

koreader/plugins/

Then restart KOReader.

After installation, Auto Scroll BD will appear in the KOReader plugin menu.

❤️ Why Auto Scroll BD?

Traditional e-readers are excellent for reading, but repeatedly swiping the screen can become inconvenient during long reading sessions.

Auto Scroll BD provides a simple solution:

Start → Set your speed → Read

No repeated swiping is required.

---

📝 Notes

Auto Scroll BD works best when the document is configured for continuous page/scrolled reading.

For the smoothest experience, Fast screen refresh mode is recommended.

Actual smoothness may vary depending on the e-ink hardware and KOReader's refresh behavior.
